## 🚀 Download → Import → Create

| 1 · Get the package | 2 · Import into Unity | 3 · Follow the exercise |
| --- | --- | --- |
| Download **TerrainLab-Students.unitypackage** using the link above. | Create an empty **Universal 3D (URP)** project in **Unity 6000.3.24f1**, then choose **Assets → Import Package → Custom Package** and import everything. | The **Terrain Lab - Student Exercise** Readme is selected for the Inspector. Open **Assets/Scenes/TerrainClassroom.unity** to begin. |

**Requirements:** Universal RP and Input System must be installed. The workshop uses **URP 17.3.0** and **Input System 1.20.0**. Find them under **Window → Package Management → Package Manager**. If Unity asks to enable the new input backends, accept and restart. In **Project Settings → Player → Active Input Handling**, use **Input System Package (New)** or **Both**.

## 📖 Your guide lives inside Unity

Select **Assets/Readme.asset**, or choose **Tools → Terrain Lab → Student Exercise** to reopen it.

The Inspector guide includes a **landscape reference image**, **collapsible sections**, step-by-step walkthroughs for the main activities, a completion checklist, and the pond challenge. Each activity explains what to click and what the result should look like. Use **Expand all** for the full exercise or open one step at a time. A Markdown copy is included at **Assets/TerrainLab/START_HERE.md**. The pond remains an independent challenge, with goals rather than a worked solution.

> **Start with the ground.** The starter contains only the sun and prepared player capsule. Create your Terrain before pressing Play, and keep Play stopped while editing.

## 🎨 What you will do

| Step | Your task |
| --- | --- |
| **Create** | Make Terrain with an 80-metre height range. Try a ground height of 20, reset it to 12, then reset its Transform. |
| **Sculpt** | Build a C-shaped mountain border with an open entrance and gentle walking route. |
| **Paint** | Add surface layers and blend grass, dirt paths, sand, and rock. |
| **Plant** | Register the oak prefab, paint small tree groups, and keep the path clear. |
| **Explore** | Walk through the landscape and improve one thing. |

### 💧 Your challenge: build a pond

Create a pond with **level water**, **banks above the surface**, and **a route the capsule can walk back out of**. Use the finished scene as a visual reference and work out your own approach. Finish the main landscape first; the pond is an extension challenge.

## 🎮 Take a walk

| Control | Action |
| --- | --- |
| **WASD / Arrows** | Walk |
| **Mouse** | Look |
| **Left Shift / Space** | Sprint / Jump |
| **Escape / Click** | Release cursor / Resume |
| **R** | Return to spawn |

Stop Play before editing. Save your scene with **Ctrl+S**, then use **File → Save Project** for terrain changes.

# Terrain Lab

Create a landscape in Unity: sculpt hills, paint paths, add trees, and explore with a capsule player.

[**Download the student Unity Package (28.4 MB)**](https://github.com/Omar-Makhlouf/Unity-Authorized-Educator-Program-Session-2026/raw/refs/heads/main/Downloads/TerrainLab-Students.unitypackage)

## Get started

1. Download **TerrainLab-Students.unitypackage** using the link above.
2. In Unity Hub, create an empty **Universal 3D (URP)** project with **Unity 6000.3.24f1**.
3. Make sure **Universal RP** and **Input System** are installed in **Window > Package Management > Package Manager**. The workshop uses URP **17.3.0** and Input System **1.20.0**.
4. Choose **Assets > Import Package > Custom Package**, select the downloaded file, and import everything.
5. Select **Assets/Readme.asset** to see the detailed exercise in Unity's Inspector. Reopen it anytime through **Tools > Terrain Lab > Student Exercise**.
6. Open **Assets/Scenes/TerrainClassroom.unity** and follow the exercise. Create the ground before pressing Play: the starting scene contains only the sun and prepared player.

If Unity asks to enable the new input backends, accept and restart. Under **Edit > Project Settings > Player > Active Input Handling**, use **Input System Package (New)** or **Both**.

**Download access:** this repository is private. Sign in with a GitHub account that has access, or get the package file directly from your teacher. Once you have the file, importing it needs no GitHub access.

## Your exercise

The Readme inside Unity walks you through:

- Creating Terrain, changing its height, resetting the ground, and setting its position to **(0, 0, 0)**.
- Sculpting an open mountain border and a gentle walking route.
- Adding surface layers and painting grass, dirt paths, and rocky slopes.
- Registering and painting trees.
- Walking through your landscape and improving it.
- **Pond challenge:** build a pond with level water, raised banks, and a safe route out.

The package includes the starter scene, **TerrainFinalized** as a visual reference, player, textures, trees, bench, and student instructions. Teacher instructions are excluded. A Markdown copy of the exercise is included at **Assets/TerrainLab/START_HERE.md**.

**Controls:** WASD/arrows walk · Mouse look · Shift sprint · Space jump · Escape release cursor · Click resume · R respawn.

Edit with Play stopped. Save your scene with **Ctrl+S**, then use **File > Save Project** for terrain changes.
